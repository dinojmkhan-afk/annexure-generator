One row per LO. Annexure 3 prints 14 LO columns per page; if there are more LOs than that, a second Annexure 3 page is added per student (LO 15 onwards), and so on. The date is optional and is printed on that LO's Annexure 2.

Generate and print

Download print-ready file saves the pages as an .html file; open it and it opens the print dialog (use this when the Print button does nothing, e.g. inside Claude). In the print window choose Save as PDF or your printer, paper A4, margins Default / None, and turn Headers and footers off. Annexure 2 prints landscape and Annexure 3 portrait automatically.
